How to use our project :
- Download zip file and Unzip file on your local server.
- Put this file inside “c:/xampp/htdocs/” .
- Open phpmyadmin
- Create Database named “ecommerce_web”.
- Import database : /ecommerce_web.sql
- Open Your browser put inside URL: "http://localhost/2TI01%20FZ/admin/index.php"
